# HSE_PopDev_Mentors_Seminar_Python_Fall_2025
HSE Population and Development Mentors Seminar 2025-2026

## First day: two 90-minute seminars for beginners

Start with the detailed [Week 1 README](01_sem/README.md): the 45-minute introduction,
course assessment and deadlines, Python/Jupyter/pip setup, and the live-coding route.
The [student materials](01_sem/day1_ready/) include the lecture PDF and four separate
notebooks for classical Python, NumPy, pandas, and Matplotlib/seaborn.
The exercise notebooks contain tasks and empty code cells for writing code during class.

The [student ZIP](01_sem/day1_ready/student_materials.zip) includes setup instructions and local
World Bank demographic data, plus the earlier Adult dataset for extra practice.
No data download is needed during class. The final course grade is based entirely on Research.
